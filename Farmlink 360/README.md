# FarmLink 360

A static web app (HTML/CSS/JS) inspired by the FarmLink system, with added features:

- **Roles:** Farmer, Buyer, Institution (schools, big hotels, supermarkets, restaurants)
- **Farmer dashboard:** products (mobile image upload), **Farmer Ledger** (earnings, expenses, profit/loss), bookings, messages
- **Buyer dashboard:** marketplace, buy/book produce, contact farmer, favorites, inquiries
- **Institution dashboard:** bulk prior booking of produce, messages, bookings

## Run

Just open `index.html` in a browser (double-click it). No server required.

Data is stored in the browser's localStorage.

## Notes

- Mobile uploads: the product image input uses `capture="environment"` so phones can take a photo directly.
